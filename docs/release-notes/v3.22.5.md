# AI Coding v3.22.5

本次同步发布 macOS Apple Silicon 和 Windows x64 版本，并提交对应的前端、Rust 后端与测试代码。

## 下载

- Windows EXE：`AI-Coding-v3.22.5-windows-x64-setup.exe`
- Windows MSI：`AI-Coding-v3.22.5-windows-x64.msi`
- macOS Apple Silicon：`AI-Coding-v3.22.5-macOS-aarch64.dmg`
- 校验文件：`WINDOWS-SHA256SUMS`、`MACOS-SHA256SUMS`

## 改进

- 修复会话恢复时误用最新会话或丢失原始目录的问题。Codex 恢复命令指向选中的会话 ID，并保留终端回滚历史；Claude Code 指向选中的 ID。原会话文件缺失或无法确认时会阻止误恢复。
- 补全 Codex 会话消息读取，改进长对话的内容展示；正在 CLI 中产生的新消息可通过刷新或自动同步更新到会话视图。
- 搜索可在精准和模糊匹配之间切换，匹配用户及 AI 回复内容，搜索结果包括归档会话。默认按当前 Agent 检索，需要时可选择合并所有 Agent。
- 改善搜索和会话列表响应，修复打开搜索结果后侧边栏或内容区消失的问题；归档与置顶可以同时生效，并可为会话设置本地显示名称。
- 设置页增加工具版本检查，显示本地版本、远端已发布版本及检测错误；检查任务限制并发，避免集中调用造成界面卡顿。bincode 使用 OpenCode 兼容检查，Claude Desktop 在支持的平台上检查。

## 安装与验证

Windows 包适用于 Windows 10/11 x64，采用当前用户安装方式；WebView2 缺失时安装程序可能联网下载。Windows 包未使用商业代码签名证书，macOS 包尚未经过 Apple 公证。

Windows 发布流程会检查前端类型、格式、单元测试和生产构建，运行 Windows Rust 编译、Clippy 与测试，并核对安装包架构与版本；随后在临时 Windows 环境中安装 MSI、观察应用启动 15 秒、卸载并验证其他文件及测试数据未被删除。`WINDOWS-VALIDATION.json` 记录本次构建源码提交和安装检查结果。这些自动检查不等同于在用户自己的 Windows 电脑上逐项人工操作。
